cortex open source · MIT

2026 · typescript, sqlite, unix sockets

A single-binary task tracker and memory layer for one engineer supervising several AI coding agents at once.

Problem
Parallel agent sessions lose context, attribute work badly and interrupt you constantly.
Decisions
One daemon per database on a private Unix socket, so every write is arbitrated and nothing is exposed to the network. Agents post updates through an agent-first CLI with --json. Live events fan out to every open terminal workspace. The TUI only interrupts when a task is blocked. Tasks double as searchable agent memory.
Outcome
Daily driver for my own agent work: about 68k lines of TypeScript with a roughly 1:1 test-to-source ratio (1,600+ tests).
